Dit ZCBS-hulpprogramma zorgt voor het:
A. Inlezen en bepalen van de type images.
B. Automatisch aanmaken van afgeleiden afbeeldingen (small/large/100pct).
C. Uploaden via ftp van deze images naar de webserver.
D. Aanmaken van de bijbehorende database records.

Documentatie:
Zie: www.zcbs.nl/docs/manual-images.pdf

==> Vergeet niet om na afloop de originele afbeeldingen op te slaan!

- Huidige map is: c:\ZCBS\Images

  Gevonden 2 bestanden in map (\images) van type: **** A ****

> Type ENTER/RETURN indien OK -- of kies een van de volgende opties/letters -- of breek het programma af:
   A : Bestandstype A: Vast aantal cijfers (= recordnummer); geen letters en andere tekens
   B : Bestandstype B: Vast aantal letters + vast alleen cijfers (= recordnummer)
   C : Bestandstype C: Willekeurig aantal letters en/of cijfers (naast - en _ geen andere tekens)
a
